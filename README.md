## 🚀 Overview
**𝗠𝗔𝗡𝗜 𝗠𝗗 ☘** is a powerful, feature-rich WhatsApp bot built with Baileys. It's designed to automate tasks, manage groups, and provide entertainment directly in your WhatsApp chats.

### ✨ Key Features
- 🎵 **Media Downloader**: High-speed downloads for YouTube, Spotify, Instagram, and TikTok.
- 🛡️ **Group Management**: Anti-link, anti-delete, and automated moderation tools.
- 🤖 **AI Integration**: Powered by GPT-4 and image generation models.
- 📱 **Easy Pairing**: Modern web-based pairing portal for quick setup.
- ⚡ **Performance**: Optimized for speed and low resource usage.

## 🛠️ Installation

### 1. Deploy to Render
Click the button below to deploy your own instance on Render:

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/MANI-077/Mani-MD-Bot)

### 2. Manual Installation
```bash
git clone https://github.com/MANI-077/Mani-MD-Bot.git
cd Mani-MD-Bot
npm install
npm start
```

---

## ⚙️ Configuration
Edit the `config.js` file to set your preferences:
- `SESSION_ID`: Your WhatsApp session ID.
- `OWNER_NUMBER`: Your phone number.
- `PREFIX`: The command prefix (default: `.`).

---

## 📜 Commands
| Command | Description |
|---------|-------------|
| `.menu` | Show the full command list |
| `.song` | Download audio from YouTube |
| `.video` | Download video from YouTube |
| `.ai` | Chat with GPT-4 |
| `.sticker` | Convert image/video to sticker |
| `.group` | Manage group settings |
