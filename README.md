## 🚀 Overview
**𝗠𝗔𝗡𝗜 𝗠𝗗 ☘** is a premium, feature-rich WhatsApp bot built with the latest Baileys version. It's designed to be the ultimate companion for your WhatsApp experience, combining utility, entertainment, and powerful automation.

### ✨ Why Mani-MD?
- 🎵 **Advanced Downloader**: Multi-API fallback system for 100% success rate on YouTube, Spotify, Instagram, and TikTok.
- 🛡️ **Ultra Security**: Anti-link, anti-delete, and anti-call features to keep your groups safe.
- 🤖 **Next-Gen AI**: Integrated with GPT-4, Llama 3, and advanced image generation.
- 🎨 **Anime Dashboard**: A superb, responsive web portal for easy pairing and system monitoring.
- 🎭 **Auto-Features**: Auto-status view, auto-reaction, and smart chatbot capabilities.

```bash
cd Mani-MD-Bot
npm install
npm start
```

## ⚙️ Configuration
The bot can be configured via environment variables or the `settings.js` file:
- `GITHUB_TOKEN`: Your GitHub Personal Access Token for cloud session sync.
- `OWNER_NUMBER`: Your phone number (with country code).
- `PREFIX`: The command prefix (default: `.`).
